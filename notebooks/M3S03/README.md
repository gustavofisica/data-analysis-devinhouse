# M3S03 — Comparação de Modelos de Regressão

Notebooks do Módulo 3, Semana 3 — treinamento e comparação de diferentes algoritmos de regressão.

## Notebooks

| Arquivo | Descrição |
|---|---|
| `decision_tree_regressor.ipynb` | Treinamento de `DecisionTreeRegressor` com MAE, RMSE e R² |
| `cross_validation.ipynb` | Validação cruzada (5 folds) na Regressão Linear com `cross_val_score` |
| `reproducibility.ipynb` | Demonstração do impacto do `random_state` e importância da reprodutibilidade |

## Base de dados utilizada

`data/input/csv/dados_AP - [M3S01] - Ex. 1 até [M3S03] - Ex. 4.csv`

pip install pandas numpy scikit-learn
