# M3S02 — Pré-processamento para Machine Learning

Notebooks do Módulo 3, Semana 2 — preparação dos dados para modelos de ML.

## Notebooks

| Arquivo | Descrição |
|---|---|
| `split_features_target.ipynb` | Separação das variáveis preditoras (X) e da variável resposta (y) |
| `train_test_split.ipynb` | Divisão da base em 80% treino e 20% teste com `train_test_split` |
| `model_metrics.ipynb` | Cálculo das métricas MAE, RMSE e R² sobre o conjunto de teste |

## Base de dados utilizada

`data/input/csv/dados_AP - [M3S01] - Ex. 1 até [M3S03] - Ex. 4.csv`
