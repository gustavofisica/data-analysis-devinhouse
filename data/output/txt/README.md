# Output Text Files

This directory contains text files generated by validation and processing scripts.

## Files

- **emails_validos.txt**: Valid emails (generated by `scripts/M1S4/email_validator.py`)
- **emails_invalidos.txt**: Invalid emails (generated by `scripts/M1S4/email_validator.py`)
- **email_gerado.txt**: Job vacancy analysis e-mail body (generated by `scripts/M3S04/generate_and_send_email.py`)

## Usage

Regenerate by running the corresponding script:
```bash
python scripts/M1S4/email_validator.py
python scripts/M3S04/generate_and_send_email.py
```
