# SQL Queries

This directory contains SQL query scripts organized by module and week.

## Structure

- **M1S8/**: Week 8 - Basic Data Query Language (DQL) with SELECT, WHERE, ORDER BY, GROUP BY
- **M1S9/**: Week 9 - Advanced SQL queries including JOINs, aggregations, CTEs, and analytics

## Modules Overview

### Module 1 - Week 8 (M1S8)

Data Query Language exercises demonstrating:
- SELECT queries with filters and ordering
- JOINs across multiple tables
- Aggregate functions (COUNT, AVG, SUM)
- Complex filtering with HAVING

See: `M1S8/README.md`

### Module 1 - Week 9 (M1S9)

Advanced query techniques including:
- Complex JOIN operations (INNER JOIN, LEFT JOIN)
- GROUP BY with multiple aggregations
- Common Table Expressions (CTEs)
- Date extraction and string concatenation
- Analytics dashboards and business intelligence queries

See: `M1S9/README.md`

## Related Files

- Database models: `/sql/modeling/`
- Database creation and normalization: `/sql/schemas/`
- Database procedures: `/sql/procedures/`
- Migrations: `/sql/migrations/`

## Getting Started

1. Review the database structure in `/sql/schemas/M1S8/create_tables.sql`
2. Load sample data using `/sql/schemas/M1S8/dml_operations.sql`
3. Execute queries from M1S8 to learn basic SQL patterns
4. Progress to M1S9 for advanced query techniques
